# Backend Course

Personal repository for the **Backend Development** course. This is where I'll be uploading all the activities, exercises, and projects completed throughout the course.

## Course Description

This course provides students with the knowledge and skills needed to develop server-side applications using modern technologies and good programming practices. It covers fundamental concepts of client-server architecture, development frameworks, database access, and deploying applications to production environments.

## Modules

| Module | Content |
|---|---|
| 0 | **About the Course** — Work and evaluation methodologies, table of contents |
| 1 | **Backend Development Fundamentals** — Concepts, JavaScript for backend, HTTP, APIs, frameworks, architecture and design patterns, asynchrony |
| 2 | **Node.js** — Node.js, npm, TypeScript, Express, routing, architecture, middleware, errors and validation |
| 3 | **Data Persistence** — Databases, MongoDB, MongoDB Atlas, Compass, driver, Mongoose and modeling |
| 4 | **Security** — Security, validation, passwords, authentication, JWT, cookies, sessions, authorization, Passport and OAuth |
| 5 | **File Storage and Management** — Multer, multipart/form-data, file validation, S3, IAM and Multer-S3 |
| 6 | **Server-Side Management Features** — Sending emails, scheduled tasks, WebSockets, Socket.IO, logging, auditing and frontend |
| 7 | **Quality, Testing and Optimization** — Automated testing, Jest, mocks, coverage, intro to integration testing, optimization and production readiness |
| 8 | **Deployment, Cloud and CI/CD** — Deployment, Render, AWS, EC2, Elastic Beanstalk, CI/CD and GitHub Actions |

## Repository Structure

Activities are organized into folders (e.g. `tarea1/`, `tarea2/`, etc.), each corresponding to a task or exercise assigned during the course.
